# Design concept — Sandra MEBEL

## Client / project

- Name: Sandra MEBEL (Кухни Шкафы Мебель на заказ Миасс Чебаркуль)
- Date: 2026-11-16
- Niche: regional custom kitchens & wardrobes (Miass / Chebarkul / Zlatoust)
- Concept-ID: 2026-11-16-sandra-product-theater-v1
- Composition-archetype: product-theater
- Forbidden-for-this-niche: quiet-luxury black/cream/gold; cream `#F4F1EA` + terracotta + serif; hero + 3 equal feature-cards; purple/indigo gradients; filmstrip-process (занято «СНОВА НОВОЕ»); passport/kraft; London atelier megabrand mimic
- Delta-from-previous: n/a as built site (Desktop history had unbuilt horizontal-scroll «Лента размера» — replaced by product-theater to avoid filmstrip carryover)

## Niche fingerprint

- Rituals: VK / звонок → бесплатный замер дома → расчёт → изготовление → монтаж в квартире
- Materials: лакированные/плёночные фасады, дубовый шпон, стальные ручки, камневидная столешница, soft-close
- Places / light: реальные кухни и шкафы в квартирах Миасса/региона; дневной свет у окна; тёплый LED под верхними шкафами
- Vernacular: замер, гарнитур, купе, фасад, фурнитура, индивидуальные размеры, расчёт
- Sensory: щелчок доводчика, холод столешницы, запах нового фасада, ровная плоскость фасада

## Unique thesis

1. Mood: спокойная уверенность монтажника — «уже стоит в квартирах», не витрина London atelier
2. Type rationale: condensed grotesque для бренда SANDRA (размер / метка фасада) + чистый geometric sans для текста — язык замера, не fashion-serif
3. Palette logic: chalk facade, graphite body, oak strip, steel handle, VK-оранж как единственный CTA-акцент
4. Composition: product-theater — full-bleed установленная кухня как сцена; бренд сильнее headline
5. Motion: медленный drift фона; staggered reveal работ; soft hover по тайлам (2–3 жеста)
6. Main gesture: гарнитур = сцена + SANDRA как hero-signal

## Anti-clone checklist

- [x] Carryover: не filmstrip / Alumni+Onest / passport-kraft из «СНОВА НОВОЕ»; не horizontal-scroll measure-tape из прежнего незакрытого черновика Sandra
- [x] Benchmark clone: homekdesign / Reform / deVOL — только ритм и фото-дисциплина, не их палитра/тип/скелет
- [x] AI clusters: нет purple-gradient, cream+#F4F1EA+terracotta, broadsheet, dark neon SaaS, hero+3 feature-cards
- [x] Brand test: без лого читается как мебель на заказ / замер в регионе — не юрист / пекарня / детейлинг
